Как настроить формулу оценки за курс в SmartLMS?

1. Зайдите в раздел Оценки вашей оболочки.

2. Отчет по оценкам → Настройки журнала оценок.

3. Дальше нужно Добавить категорию. Категории — это основные элементы контроля. Например, если формула выглядит как min(8; Семинары * 0.1 + Самостоятельные работы * 0.2 + Контрольная работа * 0.7), то тогда семинары, самостоятельные работы и контрольная работа — это категории.

4. Добавляете категорию: указываете название, указываете метод подсчета итога категории, убираете галочку в подсчете пропущенных. Эту операцию нужно проделать для всех элементов формулы оценки.
Итог категории:

  • Среднее оценок - сумма оценок оценок в категории деленное на количество оценок.
  • Среднее взвешенное оценок - среднее оценок с учетом веса (если у элементов внутри категории разная значимость).
  • Лучшая оценка - в итог категории пойдет лучшая из всех оценок внутри.
  • Сумма оценок - в итог пойдет сумма оценок всех элементов внутри категории.

5. После того, как все категории добавлены, нужно перевести расчет оценки в 10 балльную систему и оценки отображались в точности до целых.Редактировать → Редактировать настройки.

6. Настраиваете подсчет итога по курсу.

7. Теперь настроим веса категории и формулу оценки. Если формула выглядит как min(8; Семинары * 0.1 + Самостоятельные работы * 0.2 + Контрольная работа * 0.7), то сначала добавляете ID для итога каждой категории, а потом прописываете формулу.

Как ставить пропуски по уважительной причине?

1. Заходите в Оценки.

2. Выбираете ту форму контроля которую не нужно учитывать.

3. Переходите в Режим редактирования. Для людей, которым нужно не учитывать оценку по этой форме контроля, ставите галочку в столбце Исключить. Затем пролистываете страницу до конца и нажимаете Сохранить.

Как изменить оценку пользователю за форму контроля?

1. Заходите в Оценки.

2. Выбираете ту форму контроля которую нужно изменить.

3. Переходите в Режим редактирования. Для людей, которым нужно изменить оценку по этой форме контроля, ставите галочку в столбце Изменить. Меняете оценку. Затем пролистываете страницу до конца и нажимаете Сохранить.

Как выгрузить эксель таблицу с оценками из SmartLMS?

1. Заходите в Оценки.

2. В выпадающем меню вместо Отчет по оценкам выберите Экспорт.

3. Выберите формат экспорта Таблица Excel.

4. В разделе Включаемые оценки выберите элементы контроля, оценки за которые хотите включить в файл.Также если в курсе включен групповой режим, выше есть возможность выбрать Видимые группы (тех студентов, чьи оценки попадут в файл) – по умолчанию в файл будут включены оценки всех пользователей.

5. Укажите желаемую точность получаемых значений в блоке Параметры формата экспорта (обычно 2 знака после запятой).

6. Нажмите Скачать.
